# 🚀 Quick Start - 100% FREE 3D Model Generator

## Installation (2 minutes)

1. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Start the server:**
   ```bash
   python app.py
   ```

3. **Open your browser:**
   Go to `http://localhost:5000`

## That's It! 🎉

No API keys, no signup, no configuration needed!

## How to Use

### Simple Mode (Text Prompt)
Just type what you want:
- "A muscular male warrior with medieval armor"
- "Female character in casual jeans and t-shirt"
- "Sci-fi character with futuristic tech suit"
- "Base human model with no clothes for rigging"

### Advanced Mode
Use the form to specify:
- Gender (Male/Female/Neutral)
- Body type (Slim/Athletic/Muscular/etc.)
- Clothing type (Casual/Formal/Fantasy/Sci-Fi/None)
- Additional details

## Generation Time
- First time: 1-2 minutes (model loading)
- After that: 1-3 minutes per model

## Output
- Format: `.glb` (compatible with Blender, Unity, Unreal Engine, etc.)
- Download directly from the web interface
