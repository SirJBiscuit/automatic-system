📊 Live Details

Server Uptime
⏱️ How long your server has been running since last reboot. Longer uptime = more stable. Updates automatically every few seconds.
-
CPU Load Average
🔥 CPU load average over 1 minute. Lower is better! <1.0 = light load, 1-4 = moderate, >4 = heavy load. High load may slow down services.
-
Memory Used / Total
🧠 RAM usage percentage. <70% = healthy, 70-90% = moderate, >90% = critical. High memory usage can cause services to crash.
-
Disk Used / Total
💾 Storage space used. <80% = healthy, 80-95% = warning, >95% = critical. Free up space if getting full!
-
Download Speed
Min: - | Max: - | Avg: -
📥 Real-time download speed with min/max/average over last 60 measurements. Tracks data coming INTO your server. Spikes are normal during file transfers!
-
Upload Speed
Min: - | Max: - | Avg: -
📤 Real-time upload speed with statistics. Tracks data going OUT from your server. High upload = users downloading files or streaming.
-
Ping (8.8.8.8)
🌐 Network latency to Google DNS. <50ms = excellent, 50-100ms = good, >100ms = slow. "Timeout" means no internet connection!
-
Internet Speed Test
🚀 Test your actual internet speed! Click "Run Test" to measure real download/upload speeds. Takes ~30 seconds. Shows Mbps speeds.
