## 🎮 **How to Use**

### **Command Palette:**
```
1. Press Ctrl+Shift+P (or click Tools → Command Palette)
2. Type to search commands
3. Use arrow keys to navigate
4. Press Enter to execute
5. Press Escape to close
```

### **Snippets:**
```
1. Press Ctrl+K (or click Tools → Snippets)
2. Browse categories
3. Click any snippet to insert
4. Snippet appears in terminal input
5. Press Enter to execute
```

### **Settings:**
```
1. Click Settings → Preferences
2. Adjust font, opacity, zoom
3. Toggle light mode
4. Click "Save & Apply"
5. Settings persist on refresh
```

### **Themes:**
```
1. Click Settings → Themes
2. Click any theme to preview
3. Click "Save Theme" to persist
4. Theme loads on next visit
```
